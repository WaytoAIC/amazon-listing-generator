# 方法：什么是好 Listing

## 一句话

针对特定场景 × 特定人群 × 特定需求，讲清楚这个产品给出了什么样的解决办法。Listing 不只是为了被搜到，更是买家和 Alexa 购物助手（原 Rufus）用来回答问题的资料库：没写清楚，就是没证据，就不敢推荐。

## 四条原则

- 第一眼看懂：标题、标题下方的 Item Highlights、主图、前 3 张图、五点前两条、A+ 首屏。用户体验和埋词冲突时，先保证用户一眼看懂。
- 双读者：写给买家（读得懂、信得过、敢下单），也写给亚马逊系统（属性完整、关键词正确）。
- 前台表述 = 后台属性：参数、属性、说明不缺失、不打架。
- 手机优先：按手机端的信息密度、句长和图片构图来设计。图主要给人看，字主要给系统看，两者互相作证。

## 能被 Alexa 购物助手用上的四层

1. 后台属性填全、填准，和前台一致。这一层最先被用，最被信任
2. 用人话讲场景：适合谁、什么场景、有什么限制、不适合谁
3. 把买家最常问的问题主动写进五点、描述和 A+，当现成答案
4. 评论和问答是第三方证据，要对得上你在 Listing 里说的话

图片不是装饰，是给文字作证的：图里写了的，文字里要有，后台要填。

## 资料不够时怎么补

1. 产品素材：规格参数、结构材质、包装内含物、认证、卖点与差异点、常见误用和售后边界。凡是买家会问“具体是多少”的，都不能模糊。
2. 竞品：覆盖不同定位，头部、高评分、高低价位、风格差异、同适配型号。看的不是谁卖得好，而是他们把什么信息放在第一眼、每张图各说什么。
3. 评论：痛点、期望、误用、兼容性。重点是反复出现的问题类型，不是比例。
4. 关键词：按意图（功能、兼容、场景、人群、问题）、竞争强度、价值分类，为四层分配做准备。

接了数据工具时见 mcp-data-enrichment.md。

## 交付前自问

- 一眼能看懂这是什么产品吗
- 最重要的差异点在最前面吗
- 关键数字写清楚了吗
- 买家最常问的问题，Listing 自己答得上吗
- 每条宣称都找得到依据吗
- 手机上依然清晰吗
